PASOS EN TU MAC
---------------
1) Clona el repo (si aún no lo tienes):
   git clone https://github.com/samarisso-wq/Portafolio_SamarisSanchez_productDesigner.git
   cd Portafolio_SamarisSanchez_productDesigner

2) Crea la carpeta en el repo:
   mkdir -p preview/lfg-show-x7k9m2

3) Copia TODO el contenido de esta carpeta Demo dentro:
   preview/lfg-show-x7k9m2/
   (index.html, videos/, logos/, etc.)
   NO hace falta htaccess en GitHub Pages (no lo usa).

4) Opcional — robots.txt en la RAÍZ del repo (junto a index.html del portafolio):
   User-agent: *
   Disallow: /preview/

5) Cambia la clave en preview/lfg-show-x7k9m2/index.html (línea del <head>):
   window.__LFG_CONFIG_PREVIEW__={enabled:true,password:'TU-CLAVE-SECRETA'};

6) Sube a GitHub:
   git add preview/
   git add robots.txt
   git commit -m "Add private LFG Show client preview"
   git push origin main

7) Espera 1–3 min (GitHub Pages). Prueba la URL en incógnito.

GITHUB PAGES — qué SÍ y qué NO
------------------------------
SÍ: noindex en HTML, marca de agua, protect, contraseña en pantalla, enlace secreto.
NO: contraseña tipo cPanel (.htaccess no aplica en Pages).
La clave en el HTML disuade; no es seguridad bancaria (el código es visible). Para clientes suele bastar.

NO enlaces /preview/ desde tu index.html del portafolio.

COMPARTIR CON CLIENTES
----------------------
Mensaje ejemplo:
  Preview privada The LFG Show:
  https://www.samarissanchez.com/preview/lfg-show-x7k9m2/
  Código de acceso: (tu clave)
